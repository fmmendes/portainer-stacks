# portainer-stacks

Stacks para receber RTMP nativo de cameras e gravar FLV continuamente:

- [RTMP Recorder - Nginx](rtmp-recorder-nginx/README.md)
- [RTMP Recorder - SRS](rtmp-recorder-srs/README.md)

Ambas oferecem intervalo configuravel em minutos, sobreposicao entre trechos
e imagens ARM64 para Raspberry Pi 5. Consulte os READMEs para configurar o
Portainer, a camera e o armazenamento persistente.
